# QiTV 2.1: Mixed Providers and Uninterrupted Playback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every channel, film and series plays from its own provider, several providers mix in
one list, one Library and one history, and nothing that plays stops while the user browses.

**Architecture:** One `CatalogService` (with its own pinned `ProviderManager` and `EpgManager`)
per provider, held by a `Catalogs` hub that creates them on first use and routes link and guide
requests by a provider stamp on every item. Each page (the TV's channel list, the Library) talks
to a `BrowsedCatalog`: the `CatalogService` interface the screens already use, pointing at one
provider or at "All providers"; picking a source only moves that pointer. A `PageStack` replaces
the window's `QStackedWidget` so the player page can be resized into a corner over the Library.

**Tech Stack:** Python 3.14, PySide6 6.11, libVLC 3.0.20, unittest (offscreen Qt), uv.

**Spec:** `docs/superpowers/specs/2026-10-17-mixed-providers-design.md` (read it first; this plan
argues from it).

## Global Constraints

- No network or heavy I/O on the GUI thread (AGENTS.md); long-running calls run in QThread workers through `JobRunner`.
- Never create Qt GUI objects or start timers from worker threads; emit plain data.
- With a single provider configured, every list, zap, number, star, guide, history entry and stream behaves exactly as now; both setups are tested.
- Every key action has an on-screen control (the mouse audit, `tests/test_mouse_audit.py`); click targets at least 28 px at the default 1280-px window.
- Provider credentials are local only: never in the repo, docs, commits, CI, memory or subagent prompts; real checks pass them through environment variables to a throwaway config, deleted afterwards.
- Never exceed a provider's stream limit: the owner's two accounts allow 2 and 1 streams.
- Any visible window or libVLC run on the owner's Mac is muted (`--aout=dummy`, `QITV_SMOKE_MUTE=1`), brief and closed by the agent; prefer `QT_QPA_PLATFORM=offscreen`.
- Layout tests must not assume macOS font widths (CI runs the unit tests on Linux, whose default font is wider).
- Format with black and isort; flake8 syntax/undefined-name checks clean; mypy green on changed modules; `logging.getLogger(__name__)`, no prints.
- Test command for one file: `PYTHONPATH=tests uv run python -m unittest tests.<module>`; the whole suite: `uv run python scripts/run_tests.py`.

## Review Focus

1. **The same channel id at two providers** (two Xtream panels from one reseller share stream ids): they must stay two channels in All, Recent, zapping and stars, never one. Test owned by Task 1 (`ZapContext.same`) and Task 8 (`_all_live_items`).
2. **An STB token expires while the PiP from that provider plays, and the user zaps the PiP**: the failed link is made again with *that* provider's fresh sign-in (2.0's "STB links re-made once on a failed play"), not the browsed provider's. Test owned by Task 4.
3. **A provider renamed or deleted in Settings while its channel plays**: the picture keeps playing until the user changes it; the provider's rows leave the lists; nothing crashes. Test owned by Task 2 (`Catalogs.reload`).
4. **"All providers" with a provider that has never been loaded** (no cache yet): its header shows with a loading row and its setup starts; it never stays an empty header. Test owned by Task 7.
5. **Opening the Library from fullscreen or from the mini player**: from the mini player the window leaves it first, as today; in fullscreen the corner player takes its fraction of the screen. Test owned by Task 13.

- Produces (`services/catalogs.py`), `class Catalogs(QObject)`:
  - Signals: `linkReady = Signal(int, str)`, `linkFailed = Signal(int, str)`, `providerReady = Signal(str)`, `providerFailed = Signal(str, str)`, `epgReady = Signal(str)`, `contentChanged = Signal(str)` (the provider name each time).
  - `__init__(self, config_manager, registry: ProviderManager, *, runner=None, factory: Optional[WorkerFactory] = None, make_epg: Optional[Callable[[ProviderManager], EpgManager]] = None, in_use: Callable[[], set[str]] = set, parent=None)`. `registry` is main.py's `ProviderManager` and only owns `providers`; each provider gets `ProviderManager(config, provider_name=name, providers=registry.providers)` and `make_epg(that manager)`.
  - `names() -> list[str]` (Settings order) · `provider(name: str) -> dict` · `catalog(name: str) -> CatalogService` (creates on first use, no network) · `ensure(name: str) -> None` (starts that catalog's setup once: cache load + STB sign-in, in its worker) · `is_ready(name: str) -> bool`
  - `request_link(self, item: dict, *, section: str, is_episode: bool = False) -> int`: routes to `catalog(provider_of(item))`; an unstamped item goes to `config.selected_provider_name` with a debug log; `ensure()` first when that catalog was never set up (the request waits for its ready, then runs).
  - `programmes(channel: dict, now: datetime, limit: int = 8) -> list[Programme]` · `max_connections(name: str) -> Optional[int]`
  - `use_guides(names: set[str]) -> None` (Task 11 uses it; here: loads those guides, `release_epg()` on the others)
  - `reload() -> None` (Settings saved): drops catalogs of removed providers and rebuilds edited ones, except names in `in_use()`, which are dropped later, when `reload()` runs again with them out of use.
  - `shutdown() -> None`
- Produces: `EpgManager.release() -> None` (publishes an empty guide, frees memory, keeps the disk cache); `CatalogService.release_epg() -> None`.
