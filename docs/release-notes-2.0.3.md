# QiTV 2.0.3

A small update with two display fixes.

**Please always download QiTV from [Releases](https://github.com/ozankaraali/QiTV/releases)
instead of using others' distributions, which may have malware.**

## Fixes

- **Four-digit channel numbers fit.** In the channel list, numbers like 9544 were cut off. The
  number column now grows to fit the longest number in the list.
- **The guide dims the whole picture.** With the guide open, a thin line along the edges of the
  window, most visible at the top, stayed bright. The dimming now reaches every edge.

## Good to know

- The README now says when the welcome card shows: only after you delete every provider,
  including the free playlist QiTV starts with.
- See the [2.0.2 notes](https://github.com/ozankaraali/QiTV/blob/main/docs/release-notes-2.0.2.md)
  for Auto live latency, and the
  [2.0.0 notes](https://github.com/ozankaraali/QiTV/blob/main/docs/release-notes-2.0.0.md) for
  everything new in 2.0.
