# QiTV 2.5.3

**Download QiTV from [qitv.app](https://qitv.app), which picks the right build for your
computer, or from [Releases](https://github.com/ozankaraali/QiTV/releases). Please don't use
others' distributions, which may have malware.**

## New

- **Channels on the remote.** The phone's Remote tab has a Channels button beside what's on.
  It turns the arrows into the channel list, opened on the channel playing, with the groups one
  level up and a find box. Just channels, no programme guide: a tap tunes, and the volume, play
  and channel buttons stay below. Tap Channels again for the arrows; the phone remembers which
  you used.
- **The Guide finds channels too.** On the Guide's groups, the find box shows the groups it
  matches and, below them, the channels it finds among all of them, as the desktop search does.
  The Remote tab's channel list finds the same way.

## Fixed

- **Scanning a second code.** With the remote's page already open in the phone's browser,
  scanning a QiTV code with the camera now pairs at once. Before, the page ignored the new code
  until it was closed.
- **Full screen from the phone.** With another app in front, the phone's Full screen did
  nothing (macOS ignores it for a window in the background). QiTV now comes forward first, then
  goes full screen.
